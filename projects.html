Employee Management Service Project

This projects allows a fictional company manage how employees are able to view, and update records. There is an admin dashboard, in which administrators are allowed to add employees to the system, raise salaries, view reports, and records. On the employee dashboard, each employee is allowed to see only their records, pay history, and their own report.

Text Editor Project

The aim of this project is to create a basic text editor. This text editor will also highlight specific parts of the code based on the Python syntax. This will be achieved by first processing the text input. Then tokenize the code, which is where the code would be broken into smaller pieces of meaningful code. From there, parse the structure of the code, and apply the relevant syntax rules. Therefore, by the end, the text editor will highlight the important parts of the code. This would include highlighting keywords, functions, identifiers, and other elements that are a part of the Python language.

Operating Systems Project

The Process Manager is created using Java and is made to simulate the basic process management in an operating system. It allows the user to add, remove, schedule, and display details of different processes. Each process has attributes such as ID, name, priority, CPU utilizaion, memory utilization, and I/O utilization. Processes are categorized as either CPU-bound or I/O-bound based on their resource utilization.
